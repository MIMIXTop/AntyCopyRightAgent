# 🤖 AntyCopyRight Agent (Kira)

> **Интеллектуальный диалоговый интерфейс (AI-ассистент) для распределённой системы анализа студенческих работ на плагиат и заимствования.**

---

## 🧭 Видение проекта

**AntyCopyRight Agent** — это интерактивный фронтенд системы в виде Telegram-бота с автономным агентом на борту. Бот избавляет преподавателя от необходимости вручную кликать по веб-панелям, заполнять формы фильтров или отправлять запросы в API.

Преподаватель общается с ботом на естественном человеческом языке, а агент самостоятельно:
1. Вычленяет намерения пользователя (курс, предмет, группа, дедлайн, тип проверки).
2. Интерактивно доуточняет недостающие параметры (текстом или динамическими инлайн-клавиатурами в Telegram).
3. Оркестрирует запросы к микросервисам экосистемы через вызовы инструментов (**Tool Calling / Function Calling**).
4. Агрегирует сырые данные от ML-моделей и C++ сервера в лаконичные, понятные отчёты с подсветкой подозрительных работ.

## 🌐 Место в экосистеме

Проект является верхнеуровневой точкой входа в комплекс **AntyCopyRight**:

```
                  ┌───────────────────────────────┐
                  │         Преподаватель         │
                  └───────────────┬───────────────┘
                                  │ Telegram (Natural Language)
                                  ▼
               ┌─────────────────────────────────────┐
               │    AntyCopyRightAgent (Этот репо)   │
               │   • aiogram 3.x                     │
               │   • LLM Agent (Groq / OpenRouter)   │
               │   • Function Calling Orchestration  │
               └──────────────┬───────────────┬──────┘
                              │               │
      HTTP/gRPC API           │               │ REST / Task Queue
                              ▼               ▼
┌────────────────────────────────┐ ┌────────────────────────────────┐
│  AntyCopyRightCppServer        │ │   AntyCopyRightMLService       │
│  (Высокопроизводительное ядро) │ │   (Микросервис ML-анализа)     │
│  • Хранилище отчётов и работ   │ │   • Векторизация текстов/кода  │
│  • Менеджмент групп/студентов  │ │   • Поиск семантических копий  │
│  • Быстрый поиск и индексация  │ │   • Оценка схожести (embeddings)│
└────────────────────────────────┘ └────────────────────────────────┘
```

* **[AntyCopyRightCppServer](https://github.com/MIMIXTop/AntyCopyRightCppServer.git)** — ядро на C++: быстрый доступ к файлам отчетов, метаданным студентов, курсов и академических групп.
* **[AntyCopyRightMLService](https://github.com/MIMIXTop/AntyCopyRightMLService.git)** — сервис машинного обучения: алгоритмы поиска заимствований, синтаксический анализ кода и векторизация текстов.

## 💬 Пример пользовательского сценария (User Story)

> **Преподаватель:**  
> *«Привет, 2 курс сдавал лабораторные по Операционным системам. Отправь их на проверку, составь сводку и выдели самые подозрительные работы».*

### Логика работы агента:
1. **Анализ интента:**  
   LLM понимает, что цель — `проверка работ`, курс — `2`, дисциплина — `Операционные системы`.
2. **Доуточнение (Slot Filling):**  
   Агент понимает, что на 2 курсе несколько групп.  
   *Бот:* *«На 2 курсе 3 группы: 21-ИТ-1, 21-ИТ-2 и 21-ИТ-3. Проверить все или какую-то конкретную?»*  
   *(прикрепляет инлайн-клавиатуру с кнопками)*.
3. **Вызов инструментов экосистемы:**  
   * `get_submissions(course=2, subject="OS", group="all")` → запрос к C++ серверу.
   * `trigger_similarity_check(submission_ids=[...])` → постановка задачи в ML-сервис.
   * `get_check_results(task_id=...)` → опрос статуса готовности.
4. **Формирование отчёта:**  
   Бот присылает структурированную аналитическую выжимку:
   ```text
   📊 Проверка завершена! Всего проверено: 54 работы.
   
   ⚠️ Подозрение на списывание:
   1. Иванов И. (21-ИТ-1) ⇄ Петров П. (21-ИТ-2) — совпадение 94%
      • Совпадают ключевые алгоритмические блоки в файле main.cpp
   2. Сидоров А. (21-ИТ-1) ⇄ Козлов К. (21-ИТ-1) — совпадение 87%

   Все остальные работы имеют уровень уникальности выше 75%.
   Подробный PDF-отчёт доступен по ссылке: [Скачать отчёт]
   ```

## 🛠 Архитектура агента и дорожная карта инструментов (Tools)

Агент взаимодействует с миром через строго типизированные JSON-схемы инструментов:

| Инструмент | Сервис-исполнитель | Назначение |
| :--- | :--- | :--- |
| `get_current_time` | Локально | Получение актуального серверного времени и даты |
| `send_message` | Telegram API | Отправка сообщений пользователю |
| `get_academic_structure` | `CppServer` | Получение списка курсов, кафедр, предметов и групп |
| `fetch_submissions` | `CppServer` | Выгрузка метаданных сданных файлов по фильтрам |
| `start_plagiarism_audit` | `MLService` | Запуск задачи сравнения кода/отчетов на плагиат |
| `get_audit_status` | `MLService` | Проверка готовности запущенного анализа |
| `generate_summary_report`| LLM / Backend | Сборка финального отчёта с инфографикой и топом нарушителей |

## 📦 Быстрый старт для разработки

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/MIMIXTop/AntyCopyRightAgent.git
cd AntyCopyRightAgent

# Синхронизация зависимостей через uv
uv sync
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=your_telegram_bot_token
OPEN_AI_KEY=your_groq_or_openrouter_key
CPP_SERVER_URL=http://localhost:8080
ML_SERVICE_URL=http://localhost:8000
```

### 3. Запуск локально
```bash
uv run python -m app.main
```
